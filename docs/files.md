# Files

The entry of APP is `app.tsx`.

- `src/`: APP source code
  - `screens/`: APP main UI
  - `components/`: the UI components can be reused
  - `agent/`: agent core implementation
  - `model/`: model API adaptor
  - `tools/`: agent tool implementation
  - `memory/`: agent memory
- `module`: Android native module
- `scripts/`: build scripts
- `test/`: testing
  - `run.mjs`: the entry of test
